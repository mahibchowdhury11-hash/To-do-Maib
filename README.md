To Do Maib

I created a website that is a To-Do list. If you want a way to keep track of your work but keep forgetting just note it down on my website. All you need to do is Type in your task, type in the date, choose if it is a personal, school, work, or coding task. Choose the priority. Then click add task. Now you have your task added. Also if you are having any trouble finding the task you just added there is a search bar underneath the task adding section. Where you just type in your task and the results appear.

Have fun with my website!
